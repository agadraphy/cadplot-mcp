# CadPlot MCP

CadPlot MCP; revize DWG'leri taramak, pafta çerçevelerini ve layout ayarlarını incelemek,
şirket page setup'larıyla eşleştirmek ve ileride kontrollü PDF üretmek için geliştirilen
güvenlik odaklı bir MCP sunucusudur.

İlk sürüm bilerek salt okunurdur: DWG değiştirmez, plot almaz ve keyfi AutoLISP çalıştırmaz.
Yalnızca izin verilen klasörlerde dosya tarar; çalışan AutoCAD üzerinden hedefi açıkça belirtilen
çizimin layout/plot ayarlarını ve ölçü etiketli çerçevelerini inceler.

Kurulum ve araç listesi için [README.md](README.md) dosyasına bakın.
